Heresy Editor Integration

Heresy Editor is the BiasedDoom-focused Eureka fork. Its scripting workflow is built around the same sidecar directory this site documents.

The sidecar workspace

For mymap.wad, Heresy manages mymap.scripts/: the PYTHON manifest, scripts/main.py, mapscript.acs, zscript.zs, a MAPINFO with doomednums for custom actors, and the typings/ stub. Everything is plain files — edit with any editor, version with git.

A typical loop

  • Script → New Script from Template... — pick the Python ambush template; the file opens in VSCode with full completions.
  • Press F on the map and drag a trigger line across a doorway.
  • Test in Game — cross the line, watch the ambush fire.
  • Nothing happens? Script → Show Python Errors, and subscribe to line_activation_failed to catch dead triggers.

Converting and formats

Fresh maps can be created directly in UDMF (Fresh Map → Format), and existing maps convert via Manage Project → Map Type → UDMF → Save. UDMF is the recommended format for scripting: linedef ids, named args, and full activation flags. Remember that UDMF lines with two sides need the Two-sided flag, or engines render the line as a solid black void when using editor-built GL nodes.
