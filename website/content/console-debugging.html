Console & Debugging

The console (~) is where scripts talk to you. It is built for long debugging sessions: selectable text, clipboard export, and flood-proof error reporting.

Selecting and copying console text

  • Drag with the left mouse button to select scrollback text; the selection is highlighted and works across wrapped lines.
  • Ctrl+C copies the selection. With no selection it copies the input line, as before.
  • Ctrl+A selects the entire scrollback — visibly highlighted — and copies it in one step.
  • Click once, press Escape, or start typing to clear the selection. Scrolling does not disturb it.
  • copyconsole [N] copies the last N lines (default: all) to the OS clipboard with color codes stripped — no mouse required.

Python errors can't flood the console

Identical consecutive Python errors are printed once and then summarized ("the previous Python error has now repeated N times; duplicates suppressed"). A failing tick handler produces one traceback instead of 35 per second. Pending print() output is flushed before each traceback, so messages and errors appear in the order they happened.

Dead triggers

If a trigger line does nothing, the reason is almost always that its special failed. Subscribe to line_activation_failed and the console will tell you which line, which special, and which arguments. Heresy Editor auto-generates BEHAVIOR stubs so ACS_Execute markers always succeed — see Heresy Editor.
