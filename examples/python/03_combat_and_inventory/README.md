# Combat And Inventory

Bind the engine's User buttons, then use:

- **User1** — give Clip ammo, heal, play an actor sound, and show a message;
- **User2** — spawn a target, fire native hitscan, and spawn a Rocket missile;
- **User3** — apply direct and radius damage with the player as source.

The example deliberately uses Doom II class, inventory, sound, and missile
names. Adapt those names for other games.
