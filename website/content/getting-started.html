Getting Started

Ten minutes from zero to a working Python mod. You need a BiasedDoom build, a supported IWAD (e.g. doom2.wad), and a map.

1. The sidecar directory

Python mods live in a directory named after your map: mymap.wad → mymap.scripts/. The directory loads like a PK3, so it can also carry ZScript, DECORATE, and a MAPINFO.

mymap.scripts/
    PYTHON              # manifest: one entry script per line
    scripts/
        main.py         # your code
    typings/
        biaseddoom.pyi  # editor completions (optional, see VSCode page)

The manifest is just:

# BiasedDoom Python manifest: one entry script per line.
scripts/main.py

If you use Heresy Editor, this whole layout is created for you (Script → New Script from Template...).

2. The smallest useful script

import biaseddoom as bd

@bd.on("map_load")
def hello(event):
    bd.log("map loaded: " + str(bd.current_map()))

@bd.on("line_activated")
def watch(event):
    bd.log(f"line {event['line_index']} activated")

Run it:

biaseddoom -iwad doom2.wad -file mymap.wad mymap.scripts -python -warp 1

Open the console (~) and watch the messages roll in.

3. Spawning things

@bd.on("map_load")
def reinforce(event):
    bd.spawn_actor(bd.actors.DOOM_IMP, 512.0, -256.0, 0.0)
    bd.actors.spawn_random(640.0, -256.0, 0.0, kind="monsters")

bd.actors knows every actor class in the engine — browse the Actor Registry page or bd.actors.names() at runtime.

4. The rules that bite beginners

  • Events only fire when the special succeeds. A trigger line whose special is ACS_Execute with no backing script does nothing observable — subscribe to line_activation_failed to see it (see Events).
  • UDMF lines with two sides need twosided = true, or the renderer treats the line as a solid wall (a black void) when loading editor-built GL nodes.
  • Custom monsters need a DoomEdNum via MAPINFO (doomednums { 20001 = HeresyBrute }) — ZScript class headers no longer take a number.
  • Mutation APIs require single-player, non-demo sessions and an active level; violations raise RuntimeError.
  • Snapshots go stale. Dicts from bd.spawn_actor() are point-in-time copies. For live work use handles (bd.spawn(), bd.actor_ref()) and check .valid.

5. Test it like CI

biaseddoom -iwad doom2.wad -file mymap.wad mymap.scripts -python \
    -warp 1 -scripttest 700 -pyerrorlog /tmp/pyerrors.jsonl
echo $?   # 0 = pass, 1 = python errors, 2 = level never loaded

Drive the player unattended with bd.execute("+forward") / bd.execute("-forward") from a tick handler, or bd.player().set_input(...) for finer control.

6. Editor setup

Copy docs/scripting/biaseddoom.pyi into mymap.scripts/typings/ and VSCode completes the entire module. Details on the VSCode page.
