# Scripting

BiasedDoom has three independent scripting paths. Existing ACS and ZScript
content remains supported; embedded Python is an additional opt-in path for
trusted mods.

- [Embedded Python: complete tutorial, API, and test guide](python.md)
- [Embedded Python example suite](../../examples/python/) - twelve focused,
  independently packageable mods plus the full integration fixture.
- Existing glTF-specific ZScript material starts at
  [the ZScript usage guide](../gltf/zscript-usage.md).
