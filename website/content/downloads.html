Release builds are published on the GitHub Releases page. Every artifact has a matching .sha256 checksum file. A supported IWAD is required and is not included.

Current release: 4.15.12 — Python display list & examples suite

  • The Python display list: persistent screen- and world-space canvas (text, bars, rings, textures, lines) with occlusion, distance fade and health-tracked or manual-fraction bars.
  • True per-actor RGB tints for scripts (the tint batch op and Actor.tint).
  • New item_picked and secret_found events.
  • Thirteen new gameplay examples — including the modular endless horde mode 24_wave_defense — plus an interactive example launcher.
  • The boot splash now uses the current BiasedDoom banner art.
