Python Scripting for DOOM, Done Properly

BiasedDoom embeds a full CPython 3.12 interpreter alongside ACS and ZScript. Map scripts live in a plain directory next to your WAD, react to engine events in real time, spawn and mutate actors natively, and talk to your editor and debugger like a first-class toolchain.

import biaseddoom as bd

@bd.on("line_activated")
def ambush(event):
    for candidate in bd.lines(line_id=77):
        if candidate.index == event["line_index"]:
            bd.spawn_actor(bd.actors.DOOM_IMP, -128, 384, 0.0)
            bd.center_message("They're everywhere!")

Why Python?

  • Zero build step. Edit main.py, save, test the map. The sidecar directory loads like a PK3.
  • The whole standard library. JSON state, math, itertools — scripts are trusted mod code with full CPython.
  • Real tooling. Type stubs give Pylance the entire API — including all 1,558 built-in actor classes — and the DAP server lets VSCode attach to the running game.
  • Editor integration. Heresy Editor creates script workspaces, installs the typings stub, generates trigger stubs, and shows Python errors in its log window.
