# Level, UI, And Audio Operations

This interactive example uses:

- **User1** — center message plus local actor sound;
- **User2** — immediate Doom II music change;
- **User3** — a named action special with arguments;
- **User4** — normal level exit.

It also queues a console echo at startup and defines a reusable `go_to_map`
helper demonstrating explicit transitions and `CHANGELEVEL_*` flags. The Doom
sound/music names should be changed for other games.
