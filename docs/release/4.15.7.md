# BiasedDoom 4.15.7

BiasedDoom 4.15.7 is an audio-reliability, game-discovery, and scripting
release. Windows audio is now self-contained and recovers from missing or
disconnected endpoints; Steam and other platform installations can be located
without a hand-written IWAD path; and trusted mods can opt into an embedded
CPython API alongside unchanged ACS and ZScript support.

## Audio Reliability

- Official Windows builds statically bundle OpenAL Soft and libsndfile's OGG,
  FLAC, Opus, and MPEG codecs. They no longer depend on a separately copied
  `openal32.dll`, `sndfile.dll`, or `libmpg123-0.dll`.
- Active output loss uses `ALC_SOFT_reopen_device` to reopen the configured or
  default endpoint in place, preserving OpenAL buffers, sources, and music
  streams. Bounded retries keep running when Windows temporarily exposes no
  usable endpoint.
- An initialization failure switches to silent output instead of permanently
  abandoning audio, then retries with 2/4/8/16-second backoff.
- `-audiodiagnostics` now writes a complete report automatically, including on
  successful startup. Windows uses
  `%LOCALAPPDATA%\biaseddoom\biaseddoom-audio.log` and falls back beside the
  executable when AppData is unwritable.
- `snd_status` reports the backend, device, driver override, and compiled versus
  available decoder paths. `snd_listdrivers` lists every visible endpoint.
- Failed mod-sound decoding reports both the logical sound and its WAD/PK3 path.
  A decoder lifetime leak on empty decoded data was also removed.

## Automatic IWAD Discovery

- Added `-findiwads` (`-find-iwads` and `--find-iwads` aliases) to print the
  deterministic search path, validated candidates, and detected games.
- Steam discovery parses modern and legacy `libraryfolders.vdf` files plus
  per-game app manifests, follows external libraries, honors renamed install
  directories, rejects unsafe path traversal, and supports native, Flatpak,
  Snap, macOS, Windows registry, and portable Steam roots.
- Linux discovery includes `~/.steam/debian-installation`, covering Ultimate
  Doom's current combined layout and its Doom, Doom II, TNT, Plutonia, and
  rerelease data directories.
- Added `DOOMWADPATH`, deduplicated normalized paths/candidates, explicit
  `RecursivePath` support, content-based IWAD validation, and short selections
  such as `biaseddoom -iwad doom2`.

## Embedded Python API v2

- Added an opt-in embedded CPython runtime that coexists with ACS and ZScript.
  Python remains disabled until `-python` or archived `py_enabled=true` is
  deliberately selected; `-nopython` always wins.
- Root `PYTHON` manifests load same-container scripts with path validation and
  isolated module namespaces. Python is trusted arbitrary code, not a sandbox.
- API v2 exposes synchronous lifecycle, tick, actor, player, line, save/load,
  and shutdown events; filtered/prioritized callbacks; scheduled work; native
  actor/player/sector/line handles; mutations, inventory, attacks, specials,
  ACS execution, and typed public ZScript method calls.
- Persistent JSON-compatible state participates in savegames. Whole-tic budgets,
  callback fault isolation, stale-handle checks, multiplayer/demo mutation
  guards, and status/diagnostic commands contain runtime failures.
- Added twelve focused example mods, an exhaustive hybrid fixture, packaging
  helpers, syntax/package checks, and game-loop integration coverage. Their
  portable `pyscripts/` layout avoids a `PYTHON`/`python` case-fold collision
  on Windows and default macOS filesystems.
- Native Windows, Linux, and macOS packages carry the embedded runtime when
  available. The MinGW package compiles Python stubs because vcpkg's CPython
  port does not support MinGW; ACS and ZScript remain available there.

## Build, Packaging, And Documentation

- Windows CI and release builds use pinned static OpenAL Soft 1.25.1 and
  libsndfile 1.2.2 with compressed codecs and reject unexpected loose audio
  DLL dependencies.
- Added `biaseddoom-audio-probe`, which creates an OpenAL source, verifies an
  in-place reopen preserves it, and decodes real OGG and FLAC fixtures.
- Windows helpers detect incompatible stale MinGW thread-model archives,
  package the required runtime DLLs, and exercise the Windows probe under Wine
  when available.
- The vcpkg manifest explicitly pins the helper ports required by CPython
  3.12.13 without advancing the established dependency baseline.
- Bundled-codec discovery prefers vcpkg config packages on case-insensitive
  filesystems, and MinGW packaging uses GCC 13 for OpenAL Soft's required
  C++20 standard-library support.
- Added complete audio, IWAD-discovery, and Python authoring documentation plus
  the root [troubleshooting guide](../../TROUBLESHOOTING.md).

## Release Validation

The release candidate is covered by:

- clean native Linux and MinGW Windows builds;
- native and Windows/Wine OpenAL initialization, in-place reopen, OGG, and FLAC
  probes;
- full-engine playback of a PK3-provided custom OGG sound;
- successful/failing audio initialization logs and an unwritable-AppData
  fallback simulation;
- synthetic external Steam-library, renamed-install, unsafe-path, and IWAD
  content validation;
- Python source/package validation, focused-example smoke tests, and exhaustive
  save/load, event, security, and interoperability integration tests;
- shell, PowerShell, GitHub Actions, diff, package-content, and checksum checks.
